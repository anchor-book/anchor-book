# Record syntax tasks

The fixed task set for Record Line Grammar milestone 1. Each task is asked of
every variant copy written by `variants.py`, with identifiers in that variant's
form: the line grammar uses kind-coded identifiers, so `requirement-observation-only`
is `R-observation-only` and the anchor `check-observation-only` is
`A-check-observation-only`.

## Search tasks

`searches.py` measures the minimal search for each; agent sessions answer them
with their own searches.

1. **definition:** Where is the requirement `requirement-observation-only` defined?
2. **references:** Which records cite `requirement-observation-only`?
3. **draft-anchors:** Which anchors are drafts?
4. **proof-criteria:** Which criteria require proof, and to which anchor does each belong?

## Edit tasks

Answered by editing the variant copy; an edit is valid when the copy still
reads back as the same records apart from the requested change.

5. **change-methods:** Make criterion `no-execution` of anchor
   `check-observation-only` require `test` and `review`.
6. **add-authority:** Make anchor `check-observation-only` also cite the
   requirement `requirement-truthful-results`.
